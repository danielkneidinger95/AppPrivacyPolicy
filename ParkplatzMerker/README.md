# Datenschutzerklärung für „Parkplatz-Merker"

Diese Dateien sind für die Veröffentlichung über GitHub Pages vorbereitet:

- `index.html` – Datenschutzerklärung
- `style.css` – Gestaltung

## Vor der Veröffentlichung unbedingt anpassen

In `index.html` die Platzhalter ersetzen:

- `[VOR- UND NACHNAME / UNTERNEHMENSNAME]`
- `[STRASSE UND HAUSNUMMER]`
- `[PLZ ORT]`
- `[E-MAIL-ADRESSE]`
- Angaben zum Datenschutzbeauftragten, falls vorhanden

## Wichtig: Text gilt für den beschriebenen Funktionsumfang

Die Erklärung geht davon aus, dass die App:

- keinen Login und kein Benutzerkonto verwendet,
- keinen eigenen Server zur Speicherung von Parkplatzdaten verwendet,
- Parkplatzdaten lokal auf dem Android-Gerät speichert,
- Standort nur für die Parkplatzfunktion verwendet,
- keine Werbung und kein Analytics/Tracking integriert,
- lokale Benachrichtigungen nutzt,
- nur auf ausdrücklichen Wunsch eine externe Karten-/Navigations-App öffnet.

Sobald z. B. Firebase, Google Analytics for Firebase, Crashlytics, AdMob, Sentry, ein eigenes Backend, Cloud-Synchronisation, ein Reverse-Geocoding-Dienst oder ein anderer externer Dienst eingebaut wird, muss die Datenschutzerklärung entsprechend erweitert werden.

## GitHub Pages

Für eine Projektseite kann dieses Verzeichnis z. B. unter `docs/` im Repository liegen. GitHub Pages kann daraus eine URL nach dem Schema `https://<account>.github.io/<repository>/` bereitstellen.

Die URL der Datenschutzerklärung sollte in Google Play Console im Bereich für den Datenschutz bzw. App-Inhalte hinterlegt werden.
